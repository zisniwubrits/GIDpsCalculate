# 原神伤害计算器（Genshin Damage Calculator）

> 通用原神伤害计算器：以**可视化乘区节点编辑器**自由连线组合所有伤害类型。
> **前端** Vite + React + TypeScript + React Flow（网页），**后端** Python + FastAPI（公式只此一份）。

伤害公式依据社区参考页：[原神产球及附着](https://ellen.rth1.xyz/%E5%8E%9F%E7%A5%9E%E4%BA%A7%E7%90%83%E5%8F%8A%E9%99%84%E7%9D%80/index.html) 与 [羽化哲·伤害公式](https://yuhuazhe.cn/zlk/gongshi.html)。

当前范围：**常规伤害（单段直伤）+ 增幅 / 激化 / 剧变反应 + 结晶护盾 + 月·星反应**。

> 历史版本：纯 Python + tkinter 桌面版完整保留在 **`tkinter` 分支**（tag `tkinter-final`），随时可切回。

---

## 功能

- **常规伤害**：`(基础值 + 激化值 + 基础值加成) × (1+增伤+易伤-减伤) × 抗性系数 × 防御系数 × 暴击区 × 蒸发融化系数`
- **增幅反应**：蒸发 / 融化（成对系数 2.0 与 1.5）
- **激化反应**：超激化 (1.15) / 蔓激化 (1.25)，按敌人等级取基础值
- **剧变反应**：超载、超导、感电、燃烧、碎冰、扩散、绽放、超绽放、烈绽放
- **月 / 星反应**：直伤月（感电/结晶/绽放）、反应月（感电/结晶）、星超导、星扩散（风/冰/直伤），含多角色伤害分摊
- **结晶护盾量**
- **乘区节点编辑器**：卡片自由拖动摆放、拖端口连线、增删卡片、一键预设、画布缩放（Ctrl+滚轮）、框选 + 多选对齐、卡片可拖动改变大小、**撤销/重做（Ctrl+Z / Ctrl+Shift+Z 或 Ctrl+Y）**、计算卡 / 文本卡 / 变量卡 / 变量表 / 理想圣遗物等工具卡
- 输出 **未暴击 / 暴击 / 期望伤害**（有效暴击率封顶 100%）
- **工程存档**：整张画布以 JSON 保存/读取（与旧版 tkinter 工程互通）；浏览器本地自动保存，刷新不丢；计算结果可导出为可读文本
- **网页界面**：打开浏览器即用，无需安装；卡片外观、字段、预设全部由后端 schema 驱动

## 运行

需要 **Python 3.11+** 与 **Node.js 20+（含 pnpm）**。

### 0. 最省事：双击 `launcher.bat`

双击后出现菜单（命令行界面是英文，避免批处理中文在中文 Windows 下解析出错）：

```
  Genshin Damage Calculator  (Web)
    [1] Start server   (and open the browser)   ← 日常用这个
    [2] Stop server
    [3] Dev mode       (Vite HMR, needs Node)
    [4] Quit
    Choice [1]:
```

首次运行它会自己补齐缺的东西：没有 `web\dist`、**或产物比 `web\src` 旧**（例如刚 `git pull` 拿到新前端）就自动安装依赖并构建前端；系统 Python 缺 fastapi/uvicorn 就先装好（必要时自动建 `.venv`）。之后再双击就是秒开。

> 为什么还要判断「旧不旧」：只看文件在不在的话，`git pull` 后旧产物会被一直沿用 —— 后端接口全部正常、浏览器里却缺新功能，而且不报错、极难发现。
> 手动自检：`python -m server.build_check`（退出码 0 = 最新，1 = 需要重建）；`python main.py` 启动时也会在终端提醒，界面工具栏还会显示「⚠ 前端产物过期」。

也可以带参数直接调用（不弹菜单）：

```bat
launcher.bat                :: 菜单
launcher.bat 9000           :: 用 9000 端口启动
launcher.bat stop           :: 关闭默认端口(8777)上的服务
launcher.bat stop 9000      :: 关闭 9000 端口上的服务
launcher.bat dev            :: 开发模式：后端 + Vite（前端热更新）
launcher.bat 8777 --reload  :: 端口后面的参数原样转给 main.py
```

### 1. 手动装依赖

```bash
pip install -r requirements.txt      # fastapi / uvicorn（含测试用的 httpx、pytest）
cd web && pnpm install               # 前端依赖
```

### 2. 用法一：直接跑（后端托管已构建的前端）

```bash
cd web && pnpm build                 # 构建前端到 web/dist（只需在改动前端后重跑）
python main.py                       # 启动后端并自动打开浏览器
```

- 默认地址 <http://127.0.0.1:8777>（端口可用 `--port 9000` 改）。
- 若还没构建前端，打开该地址会看到一个「后端已就绪」的提示页，按提示先 `pnpm build` 或改用下面的开发模式。

### 3. 用法二：开发模式（改前端代码即时生效，推荐）

```bash
python main.py --no-browser          # 终端 A：后端（8777）
cd web && pnpm dev                   # 终端 B：前端（http://127.0.0.1:5173）
```

Vite 已把 `/api` 代理到后端；后端换端口时用环境变量指过去：
`$env:DSH_API="http://127.0.0.1:9000"; pnpm dev`（PowerShell）。

### 4. 测试

```bash
python -m pytest -q                  # 后端：公式 47 项 + 图求值 46 项 + 接口 29 项
cd web && pnpm test                  # 前端：模型 20 项 + 表格 7 项 + 界面集成 21 项
cd web && pnpm typecheck             # 前端类型检查
```

### 5. 其它

```bash
launcher.bat dev                     # = 后端 + Vite 前端热更新
python main.py --reload              # 后端代码热重载（开发用）
cd web && pnpm preview               # 单独预览前端构建产物
```

## 使用说明

整个页面就是**乘区节点画布**（一个界面即可完成所有伤害类型），**启动时为空白画布**，**没有单独的右侧结果栏** —— 结果直接显示在画布卡片上（链上有暴击区时 ★结果卡片显示 `未暴击 ｜ 暴击 ｜ 期望`，没有暴击区则只显示一个数值）。画布上的改动（连线/增删/改值）会即时重算。顶部工具栏还有**工程名、当前保存目录、撤销/重做、保存工程 / 打开工程 / 导出结果、缩放与状态提示**。

**软件内教程**：按 **F1**（或点右上角「教程 (F1)」按钮）可随时打开内置使用教程，包含连线、增删卡片、缩放、看结果、算式与变量、工程存档等全部说明。

**节点编辑器（自由连线 + 增删卡片）**
- **左侧纵向菜单栏**（可滚动）分区排列（直伤乘区 / 反应源 / 星月部件 / 工具）：点任意按钮即可添加对应卡片：基础值、增伤区、抗性区、防御区、暴击区、增幅反应、擢升、加法、激化值、剧变反应、结晶护盾、**属性源 / 基准值源 / 系数 / 倍率 / 基础提升 / 精通增益 / 星超导系数**、**计算卡**、**文本**、**变量**、**变量表**、**赋值变量**、**理想圣遗物**、★结果。
- **计算卡**：一张**无端口、不参与连线**的小工具卡。可**自定义标题**，在其「表达式」里填算式（支持 `+ - * / // % **` 与括号，兼容全角 `× ÷ ＋ － （）`、千分位逗号与换行），卡片底部实时显示计算结果；点 **复制** 可把输出数值复制到剪贴板（纯数字、无千分位/科学计数法，便于直接粘贴到其它输入框）。表达式非法时会显示「错误(原因)」。
- **文本卡片**：一张**无端口、不参与计算**的纯标注卡片，直接输入说明文字即可；与其它卡片一样**可拖动、可拖手柄改变大小**。在卡片上 **右键** 弹出菜单可调字号（加大字号 / 减小字号 / 重置字号 / 复制文本），字号随 JSON 工程保存/恢复。
- **画布缩放**：工具栏与画布右下角都有 **－ / ＋ / 百分比 / 适应**（适应 = 缩放到刚好容纳所有卡片），也可 **Ctrl+滚轮** 缩放（范围 25%~250%）；滚轮本身用于平移画布。缩放比例随 JSON 工程保存/恢复。
- **可拖动改变大小（所有卡片）**：**选中卡片后四周与四角会出现缩放手柄**，拖动即可调整宽高（最小 160×90），输入框会随卡片宽度伸展；卡片尺寸会随工程一起保存/恢复。
- **星/月/剧变的「源」已拆分为多个乘区部件**，可自由组合。例如：
  - 月·直伤 = `属性源 → 系数(3/1.6/1) → 倍率 → 基础提升 → 精通增益 → 抗性区 → 暴击区 → 擢升 → 结果`
  - 月·反应 = `基准值源 → 系数(1.8/0.96) → 基础提升 → 精通增益 → 抗性区 → 暴击区 → 擢升 → 结果`
  - 星·超导 = `属性源 → 系数(hit倍率) → 倍率 → 基础提升 → 精通增益 → 抗性区 → 暴击区 → 擢升 → 结果`
  - 星·扩散 = `基准值源 → 系数(0.75 / 2或3) → 基础提升 → 精通增益 → 抗性区 → 暴击区 → 擢升 → 结果`
  - 剧变 = `基准值源 → 系数(反应倍率) → 精通增益 → 抗性区 → 结果`
  - 激化值 = `基准值源 → 系数(1.15/1.25) → 精通增益 → 结果`（再用加法卡并入基础值）
  - 「精通增益」卡片的「系数 k / 分母」按反应类型取值：**星月 6/2000**、**剧变 16/2000**、**激化 5/1200**（上面的预设都已自动填好）。
- 左侧**一键预设**按钮（普通直伤 / 月·直伤 / 月·反应 / 星·超导 / 星·扩散 / 星·扩散直伤 / 剧变反应 / 激化值）会自动用这些拆分部件搭好一条链。**预设不含 ★结果 卡片**（需要汇总时自行拖一张 ★结果 接在链尾）；**预设也不会清空画布**，而是在**空白位置**另起一行创建，可同时保留多条链对比；需要清空时点工具栏「新建…」。
- **变量卡片**：一张**无端口**的卡片，卡片内就是**一整块多行文本框**（不显示字段标签、随卡片大小自适应，拖右下角 ◢ 改大小），用来**定义全局变量**，每行写 `名称 = 表达式`（可引用前面定义的变量），例如：  ```
  攻击力 = 1000
  倍率 = 200
  基础伤害 = 攻击力 * 倍率
  ```
  定义后，**所有卡片的数值/百分比输入框、计算卡表达式都能引用变量名**，如属性值填 `攻击力+500`、倍率填 `倍率/2`、计算卡写 `基础伤害*2`。未定义的变量会显示「未定义变量: xxx」。**卡片底部只列出这张卡片自己定义的变量**及其当前生效值（同名被结果卡/赋值卡覆盖时显示覆盖后的值；算不出来的行显示 `未解析`），想看**全部**变量用「变量表」卡片。变量卡也随 JSON 工程保存/恢复。
- **★结果卡片的三元组变量**：结果卡片**外观与原来完全一致**（不显示任何多余输入框）；在卡片上**点右键 →「设置结果变量…」**，在弹出的窗口里把三元组分别命名为**三个互不相同的变量**——未暴击变量 / 暴击变量 / 期望变量（留空表示不定义），右键菜单里还有「清除结果变量」可一键清空。例如把期望变量填 `期望伤害`，之后任何数值框、变量卡片或计算卡都能引用它（计算卡写 `期望伤害/20*60` 即得 DPS，变量卡写 `秒伤 = 期望伤害/时间` 同样有效）。变量名需是合法标识符（支持中文，如 `期望伤害`），非法名字会被忽略；同名时以结果卡片上的名字为准；多张结果卡片都可用，各自独立命名。名字随 JSON 工程保存/恢复。注意：不要反过来让结果链依赖「由结果变量算出的变量」，否则会形成循环引用。
- **折叠卡片**：在卡片**标题栏右键 →「折叠卡片」**，卡片收起为只剩**卡片类型**的窄条（字段区与底部输出都不再渲染，端口保留、连线照常）；再右键点「展开卡片」恢复。折叠属于**界面状态**：会随工程 JSON 与本地自动保存一起保存/恢复，但**不进 `/api/evaluate` 载荷**，所以折叠/展开不会触发重算。
- **右键菜单**：文本卡片右键为字号菜单；★结果卡片右键为「设置结果变量… / 清除结果变量 / 折叠卡片 / 删除卡片」；计算卡、★结果等有输出的卡片还可「复制输出数值」（纯数字，便于粘进其它输入框）。
- **变量表卡片**：调色板「变量表」可添加一张**样式与「理想圣遗物」卡片相同**的表格（两列：**变量 / 值**），**实时列出当前所有可用变量** —— 变量卡片里定义的，以及 ★结果卡片命名的三元组变量，随画布改动即时刷新；没有变量时显示一行「（暂无变量）」。**可点选单元格，或按住拖动框选一块区域**，选中后 **Ctrl+C 复制**（未选中时复制整表，TSV 格式，可直接粘进 Excel）。卡片无端口、不参与连线与计算，可拖动、可改大小，并随工程 JSON 保存/恢复。
- **赋值变量卡片**：把**其它卡片的输出连到这张卡**，填一个**变量名**、选一个**取值**（未暴击 / 暴击 / 期望，默认期望），这条链的值就赋给了该变量，之后任何数值框、变量卡片、计算卡都能引用它（例：赋值 `面板攻击力` 后，别的卡片里写 `面板攻击力*2`）。它是一张**纯汇点**卡片：**有输入端口、没有输出端口**，**不参与结果链**，只登记变量；卡片底部显示 `赋值 变量名 = 当前值`，变量名为空或非法时不登记（非法名会像变量卡那样被忽略）。同名优先级：**赋值变量卡 > ★结果卡三元组 > 变量卡片**；注意别让它的上游再引用它自己定义的变量（会形成循环，此时不登记）。变量名随工程 JSON 保存/恢复，卡片同样**支持折叠**。
- **角色容器卡片（抽象角色 / 命名空间）**：调色板「角色」添加一块**虚线淡蓝面板**，把画布上的卡片拖进面板范围里，它们就算**属于这个角色**（判定看**卡片中心**是否落在面板矩形内，嵌套时取最小的那个；**拖动面板不会带走里面的卡片**）。面板**主体不拦鼠标事件**——在它上方照样能拖出框选；**框选不会把面板自己选进来**（React Flow 的框选不看 `selectable`，所以这条规则由前端单独守：框选期间忽略容器的选中变化），想选中面板 / 改大小 / 删除它请**点它的标题栏**。角色名**完全自定义**（抽象角色也行：`主神`、`主C`、`辅助`、`配置A`…），因为要用在 `名字::变量` 的写法里，所以不能带空格、`::`、连续下划线，也不能数字开头；新建时自动叫 `角色1`、`角色2`…（不重名，随时可改）。面板**没有端口、不参与计算**，卡片标题栏会显示所属角色的小徽标，面板内显示当前里面的卡片数。**归属是按位置实时推导的，不会写进工程 JSON**（存了反而会跟画布不一致），只在求值载荷里作为 `role` 传给后端；拖动卡片时只有**跨过容器边界、归属真的变了**才会重新求值。
- **角色命名空间（`角色::变量`）**：角色容器里的卡片登记的名字会自动带上角色前缀——变量卡写 `攻击力 = 1000`，在「雷神」面板里实际就是 `雷神::攻击力`；★结果卡的三元组变量、赋值变量卡的名字同理。**读变量时先本角色、再全局**：面板里的卡片写 `攻击力` 会先取本角色的那份，本角色没有才回落到全局；写全名 `胡桃::攻击力` 在任何地方都取得到。因此**两个角色可以有同名变量且互不干扰**（对比两套配置特别方便），而**不带前缀的名字就是全局变量**（旧工程照旧可用）。变量表里显示完整名字（`雷神::攻击力`），导出报告里的节点也会带上所属角色标注。**名字里不能含连续两个下划线**（`__` 保留给内部拼接，写了会被忽略并在卡片下方显示「未解析」）。全角冒号也认（`雷神：：攻击力`）。
- **卡片命名（`卡片名::输出`）**：在任何卡片上**右键 →「命名卡片…」**给它起个名字（例：`雷神增伤`）。名字以**徽标**显示在标题栏（**不占卡片版面**），命名后就能像变量一样引用这张卡的输出：**裸名 = 该卡的期望值**，`名字::暴击` / `名字::未暴击` 取另外两个分量——对比两套配置、把某张卡的中间结果接到别处都方便。卡片名是**全局扁平**的（不套角色前缀，任何角色里都能引用）；**重名时第一张生效**并在状态栏提示；与真变量同名时**真变量优先**；引用成环会明确报错。**角色容器卡不参与命名**（它的身份是「角色名」）。**命名空间里的变量一律显示成 `X::Y`（如 `火神::最终伤害`）**；标题栏上的角色/卡片名徽标只显示名字本身，**不带尾随的 `::`**（后面没有字段时不显示分隔符），完整用法写在悬停提示里。
- **角色面板（属性表）与拐力箭头**：「角色」不只是一个名字，它有一块**面板**（原神黑话：角色属性表）。面板项**就是本角色命名空间里的变量** —— 写在本角色内的「变量」卡片里，用**固定 ASCII 词表**命名：

  | 宏 | 含义 | 宏 | 含义 |
  |---|---|---|---|
  | `atk` | 攻击力（喂「白值」） | `res_shred` | 减抗（喂「敌人抗性%」，取负） |
  | `atk_pct` | 攻击%（喂「大增益%」） | `def_shred` | 减防% |
  | `atk_flat` | 小攻击（喂「小增益」） | `ignore_def` | 无视防御% |
  | `crit_rate` / `crit_dmg` | 暴击率 / 爆伤 | `base_boost` / `month_dmg` | 基础提升%（月增伤同此） |
  | `em` | 精通（喂所有反应卡与精通增益） | `elevate` | 擢升% |
  | `dmg` | 增伤（喂「增伤区净%」） | `reaction_dmg` | 反应增伤% |

  **面板的编辑入口**：右键角色标记 →「**角色面板…**」，弹窗上半部分是**可编辑的宏表**（每个宏都有中文名与「喂给哪张卡」的提示，值可写算式与变量），下半部分是**拐力统计**（OUT：本角色给了谁多少 ／ IN：收了谁的多少）。面板宏也直接存在角色卡自己的字段里（随工程 JSON 保存），同样名字写在角色内的「变量」卡片里也认，但**角色卡上的面板优先**。

  **一个面板项有四个名字**（消除"到底指哪个值"的歧义）：`角色::atk` = **生效值**（自身 + 收进来的拐）、`角色::own::atk` = **纯自身**、`角色::out::atk` = **对外提供的**（= 自身，"宏就是对外值"）、`角色::in::atk` = **收进来的拐**（多来源相加，没被拐就是 0）。在角色内可省略角色名，直接写 `own::atk` / `out::atk` / `in::atk`（写成 `::in::atk` 也行，前导 `::` 表示"本角色"）；面板宏之外的普通变量同样支持这四个名字。变量表里只列基础名，不列这三套子命名空间。

  **想单独声明"我给出去多少"**（与自己面板值不同）：在变量卡片或角色面板里写 `out::atk_pct = 40`，拐力箭头就按这个值给（不写时默认等于自身值）；反过来 `in::` 是"收进来的"，由拐力派生，自己写它不生效。⚠️ 用 `in::同名` 定义自己会让生效值翻倍（`atk_pct = in::atk_pct` 会变成 自身 40 + 收到 40 = 80），状态区会给出提示；**a 这种被拐的角色什么都不用写**，裸名 `atk_pct` 本身就含拐。

  **面板项之间可以互相引用**（如 `atk_flat = atk*0.05`），引用 `in::` / `own::` 也认：这些名字要等拐力算完才存在，所以会在拐力之后**补算一遍**（修掉了"写了 `in::` 的定义被静默丢掉、下游报未定义变量"的坑）。⚠️ 但别用 `in::` 给自己定义**同名**面板项 —— 生效值 = 自身 + 收进来的，这么写会翻倍；要"含拐后的值"就让卡片字段留空（自动吃面板）或直接读裸名 `atk_pct`。

  **卡片字段留空 → 自动用本角色面板兜底**；字段自己写了值就以卡片为准（注意：新建卡片的字段已带默认值，**要先清空输入框**才会吃面板/拐力）。吃到面板或拐力的卡片，底部会标出「**含面板**」「**含拐**」，鼠标悬停能看到具体是哪几个字段。面板项同时是普通变量，算式里可直接引用（如白值填 `atk*1.5`）。**拐力箭头**：从角色标记左上角标签**上方**的端口拖到另一个角色标签上方的端口（虚线暖色），等于把这个角色的**面板值加到目标角色的同名面板项**上；多来源**相加**、**不传递**（只看直接箭头，`C→A→A→B` 时 B 只拿到 A 自己的面板值）。变量表里会把「含拐」后的面板值显示出来（如 `火神::atk_pct = 50` = 自身 10 + 拐 40）。
- **多选与对齐**：**按住 Shift 点卡片**可多选/取消多选，也可以在空白处**按住左键框选**一片卡片；左侧「选中的卡片」区显示已选数量，并提供 **左对齐 / 顶对齐 / 水平居中 / 垂直居中** 与「取消选择」（快捷键 `Ctrl+A` 全选、`Esc` 取消选择）。
- **未保存提醒与本地自动保存**：改动会**自动存到浏览器本地**（刷新/关掉标签页都不丢，下次打开自动恢复）；若有改动还没导出成文件，关闭页面时浏览器会提示确认。
- **所有卡片的数字输入框都支持算式**：任意数值/百分比字段都可填 `70+30`、`352+674`、`200*3`、`(100+50)*2`、以及变量名等，程序会先求值再计算（例如倍率填 `70+30` 等效于 `100`）。支持 `+ - / // % **` 与括号，兼容全角 `× ÷ ＋ － （）` 与千分位逗号；非法输入按默认值处理。
- 每张卡片**左入右出**：从右侧**输出端口**拖到另一张的**左侧输入端口**即可连线；**点击连线选中后**，中点会出现一个小 **✕** 可直接删除（也可以选中后按 `Delete`）；卡片右上 **✕** 可删除卡片（同时清理相关连线）。会形成环路的连线会被拒绝。
- **连线可读性**：连线为**横平竖直的正交折线**（起点/终点都**垂直于卡片边**水平进出），**直角拐弯处为圆角**，箭头指向目标端口。**鼠标悬停某张卡片**时，与它相关的连线会**高亮**、其余连线**变淡**，便于追踪传递关系。
- **理想圣遗物卡片**：调色板「理想圣遗物」可添加一张**带边框的表格**（四列：属性 / 强化区间 / 最高区间 / 平均值，五星满强化）。**可点选单个单元格，或按住拖动选择一块矩形区域**，选中后 **Ctrl+C 复制**（单格复制原文，多格/多行复制为 TSV，可直接粘进 Excel）；未选中时复制整表。表格只读、**没有复制按钮**，卡片可拖动、可改大小。
- **加法卡片**：**固定 2 路输入**（不支持扩展）——把两路输入逐分量相加（未接的一路记 0）；要合并三路就串两张加法卡。
- 卡片**只能拖动标题栏**来摆放（避免在输入框/表格里误拖），可自由排列；空白处按住左键框选卡片，按住**中键/右键拖动或滚轮**可平移画布。
- 计算方式：从 **★结果** 卡片沿连线**反向溯源**求值；未接入结果的卡片只展示自身输出。每个节点维护 **未暴击 / 暴击 / 期望** 三元组（由暴击区节点产生暴击与期望）；卡片底部在三条路**不同时**会显示 `未暴击 ｜ 暴击 ｜ 期望`，相同则只显示一个输出值。

结果直接显示在画布卡片上：**每张乘区卡片底部会显示本卡的系数与该步输出**，系数**统一用 `×` 前缀**（例如抗性区填 `-40` → 卡片显示 `抗性系数 ×1.200 ｜ 输出 …`；暴击区显示 `暴击系数 ×2.000 ｜ 期望系数 ×1.500`）；**链上经过暴击区时**，★结果卡片与暴击区及之后的卡片显示 **未暴击 / 暴击 / 期望伤害**；**结果链没有暴击区（或暴击区三条路数值相同）时**，结果卡片只显示一个简洁数值（`结果 …`），并在后面列出该结果**绑定的变量名**（`结果 2000.00 ｜ 变量 期望伤害`），方便对照引用。

**有效暴击率封顶 100%**：期望伤害中的暴击率按最多 100% 计入，超过 100%（百爆溢出）的部分被截断、不再额外增益（结果显示「有效暴击封顶100%」）。

**输入框支持长算式**：输入框已加宽，方便粘贴/输入如 `352+674+12*3` 这类较长算式。

**导出计算**：工具栏 **导出结果…** 由**后端直接写文件**：在同目录生成 `<工程名>_<时间戳>.txt`（如 `雷神_20260909_202705.txt`），每次一个新文件、不覆盖旧报告。文件为可读文本：含保存时间、输入参数快照（分组成 `标签 : 值`）、以及完整的计算过程与节点求值过程。

**新建项目**：工具栏 **新建…** 会先问工程名，然后**完整重置** —— 清空画布、清空工程名、清空撤销历史、重置浏览器本地自动存档（**磁盘上已保存的文件不动**，保存目录也不变）。原来那个只清卡片的「清空画布」按钮已并入这里（工具栏与侧栏都不再有单独的「清空」）。

**工程存档（JSON）**：工具栏 **保存工程…** 是**一键保存** —— 后端直接写到工具栏显示的 **保存目录** 里，文件名 `<工程名>.json`，**同名直接覆盖**（Ctrl+S 语义），不弹任何下载/保存对话框；**打开工程…** 会弹出**本机原生文件对话框**，后端记住所选工程所在目录（**从哪读就往哪存**），读回后完整恢复画布。还没打开/保存过任何工程时，默认目录是项目下的 `private/projects/`（已被 .gitignore 忽略），记忆写在 `private/save_config.json`。工程名显示在工具栏，保存时作为文件名。**画布背景上有一层浅色斜字水印，内容就是工程名**（还没命名时显示「未命名」），改名即时同步；水印贴在画布平面上，随平移/缩放一起动，位于所有卡片之下，且不响应鼠标。JSON 与**旧版 tkinter 工程的格式完全一致**，两边互通。除此之外，画布每次改动都会**自动存进浏览器本地**，刷新页面自动恢复。

**撤销 / 重做**：`Ctrl+Z` 撤销、`Ctrl+Shift+Z`（或 `Ctrl+Y`）重做；采用快照式记录，编辑停顿约 0.45 秒自动记一步，最多保留 80 步。

**数字框支持算式**：所有数字输入框都可用 `+ - * / ** ( )` 运算，也兼容 `× ÷ ＋ － ，` 等全角符号，例如属性值填 `352+674`、倍率填 `200*3` 都会先求值再参与计算。非法输入按默认值处理。

**攻/生/防的“大/小增益”前置乘区**：直伤类所输入的属性值按
`最终属性 = 白值×(1 + 大增益%) + 小增益` 计算（例：`1000×(1+46.6%)+311 = 1777`）。
「基础值」卡片与「属性源」卡片都已拆成 **白值 / 大增益% / 小增益** 三格。

### 常用参数（注意单位）

| 分组 | 参数 | 说明 |
|------|------|------|
| 基础值 | 属性值、倍率 | 倍率填百分数（如 `200` 表示 200%）|
| 增伤区 | 增伤区净% | 填增伤+易伤-减伤三者合计的净加成（如 `46.6`）|
| 抗性区 | 敌人抗性 | 填百分数（如 `10` 表示 10% 抗性）|
| 防御区 | 角色/敌人等级、减防、无视防御 | 减防上限 90%、无视防御上限 100% |
| 暴击区 | 暴击率、暴击伤害 | 填百分数 |
| 增幅反应 | 配方、元素精通、反应增伤 | 命中护盾时不计蒸发融化系数 |
| 激化反应 | 超激化/蔓激化、精通、等级 | 附加到常规伤害的激化值 |
| 剧变反应 | 配方、精通、等级、反应增伤 | 独立伤害，不受增伤/减防，不能暴击 |
| 结晶 | 精通、护盾强效 | 计算护盾量 |

## 公式说明（摘自参考页）

**常规伤害**
```
最终伤害 = (基础值 + 激化值 + 基础值加成)
           × (1 + 增伤% + 易伤% - 减伤%)
           × 抗性系数 × 防御系数 × 暴击区 × 蒸发融化系数
```
- 基础值 = 属性值 × 倍率（攻击力/生命值/元素精通/防御力均可）
- 命中护盾（无数值）不计算蒸发融化系数

**抗性系数**
```
抗性 <= 0          : 1 - 抗性/2
0 <= 抗性 <= 75%   : 1 - 抗性
75% <= 抗性        : 1/(4×抗性+1)
```

**防御系数（角色攻击敌人，减防/无视作用在分母敌人防御项）**
```
角色等级+100
----------------------------------------------------------------------------------
(角色等级+100) + (敌人等级+100) × (1 - 减防) × (1 - 无视防御)
```
减防上限 90%、无视防御上限 100%；两者各自相乘作用在敌人防御项上，因此减防会使伤害提升。

**蒸发融化系数**
```
基础系数 × (1 + 2.78×元素精通/(元素精通+1400) + 反应增伤%)
```
基础系数（增幅反应区卡片里以“打”字标注方向并直接显示倍率）：**蒸发·水打火 ×2.0**、**融化·火打冰 ×2.0**、**蒸发·火打水 ×1.5**、**融化·冰打火 ×1.5**。注意系数是**成对相同**的（2.0 一档、1.5 一档），所以选到同一档的蒸发与融化，伤害会相同，这是符合游戏规则的。

**激化值 / 剧变伤害 / 结晶盾量** 等见 `genshin_dmg/damage.py` 内注释。

### 月 / 星反应（进阶，参考 [羽化哲·伤害公式](https://yuhuazhe.cn/zlk/gongshi.html)）

月 / 星反应无视防御、不受益于常规增伤/易伤/减伤，但受益于元素精通与暴击，公式带 **擢升** 与 **基础提升%**：

```
直伤基础 = 直伤系数 × 属性 × 倍率 × (1+基础提升%) × (1 + 6×EM/(EM+2000) + 增伤%)
最终直伤 = (直伤基础 + 额外提升) × 抗性系数 × 暴击区 × 擢升

反应值   = 等级基础(1446.85，95/100级换 1561.46/1674.81)
           × 反应倍率 × (1+基础提升%) × (1 + 6×EM/(EM+2000) + 增伤%)
           × 抗性系数 × 暴击区 × 擢升
```

- **直伤月**：月感电 系数 3 / 月结晶 1.6 / 月绽放 1（属性可为攻击力/精通等）
- **反应月**：月感电 ×1.8、月结晶 ×0.96；月绽放只有直伤
- **星超导**：直伤基础倍率随 hit 数（附着次数 0~12）变化，hit 1 起等步长（每层 +0.05）：`1.0, 1.45, 1.5, 1.55, 1.60, 1.65, 1.70, 1.75, 1.80, 1.85, 1.90, 1.95, 2.0`
- **反应星扩散**：风 ×0.75；冰随风涡系数 1~2 → 2、3~6 → 3
- **星扩散直伤**：系数 1
- **多角色分摊**（反应月感电/结晶）：`最高×1 + 第二高×1/2 + 第三高×1/12 + 第四高×1/12`（`distribute_damages`，自动按伤害从大到小排序）。

### 两处跨参考源的差异提醒

- **激化值**：采用 `5×EM/(EM+1200)`（ellen 页口径，**已确认**）。羽化哲页写作 `+2000`，本项目不采用；`test_damage.py::test_mastery_term_is_1200` 锁定该口径，勿改。
  - 手动搭激化链时，「精通增益」卡片请填 **k=5 / 分母=1200**（「激化值」预设已自动填好）。
  - 星 / 月反应与剧变反应统一用 `+2000`（k=6 星月、k=16 剧变）。
- **扩散倍率**：ellen 页 0.6，羽化哲页 0.65。当前代码沿用 ellen（0.6）。
