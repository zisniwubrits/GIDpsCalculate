# 原神伤害计算器（Genshin Damage Calculator）

> 纯 Python + tkinter 的通用原神伤害计算器：以**可视化乘区节点编辑器**自由连线组合所有伤害类型，零第三方依赖。

一个通用的原神伤害计算程序，使用 **Python + tkinter** 图形界面（无需安装第三方库）。

伤害公式依据社区参考页：[原神产球及附着](https://ellen.rth1.xyz/%E5%8E%9F%E7%A5%9E%E4%BA%A7%E7%90%83%E5%8F%8A%E9%99%84%E7%9D%80/index.html) 与 [羽化哲·伤害公式](https://yuhuazhe.cn/zlk/gongshi.html)。

当前范围：**常规伤害（单段直伤）+ 增幅 / 激化 / 剧变反应 + 结晶护盾 + 月·星反应**。

## 功能

- **常规伤害**：`(基础值 + 激化值 + 基础值加成) × (1+增伤+易伤-减伤) × 抗性系数 × 防御系数 × 暴击区 × 蒸发融化系数`
- **增幅反应**：蒸发 / 融化（成对系数 2.0 与 1.5）
- **激化反应**：超激化 (1.15) / 蔓激化 (1.25)，按敌人等级取基础值
- **剧变反应**：超载、超导、感电、燃烧、碎冰、扩散、绽放、超绽放、烈绽放
- **月 / 星反应**：直伤月（感电/结晶/绽放）、反应月（感电/结晶）、星超导、星扩散（风/冰/直伤），含多角色伤害分摊
- **结晶护盾量**
- **乘区节点编辑器**：卡片自由拖动摆放、拖端口连线、增删卡片、一键预设、画布缩放（Ctrl+滚轮）、卡片可拖动改变大小、**撤销/重做（Ctrl+Z / Ctrl+Shift+Z 或 Ctrl+Y）**、计算卡 / 文本卡 / 变量卡 / 理想圣遗物等工具卡
- 输出 **未暴击 / 暴击 / 期望伤害**（有效暴击率封顶 100%）
- **工程存档**：整张画布以 JSON 保存/读取；计算结果可导出为可读文本

## 运行

需要 Python 3.8+（tkinter 为标准库，Windows 官方安装包自带）。

```bash
# 方式一：启动图形界面
python main.py

# 方式二：运行公式单元测试
python -m unittest test_damage -v
```

## 使用说明

整个窗口就是**乘区节点画布**（一个界面即可完成所有伤害类型），**启动时为空白画布**，**没有单独的右侧结果栏** —— 结果直接显示在画布卡片上（★结果卡片显示 `未暴击 ｜ 暴击 ｜ 期望`）。画布上的改动（连线/增删/改值）会即时重算。主窗口默认显示在屏幕中央。

**软件内教程**：按 **F1**（或点左下角「教程 (F1)」按钮）可随时打开内置使用教程，包含连线、增删卡片、缩放、看结果、算式与变量、工程存档等全部说明。

**节点编辑器（自由连线 + 增删卡片）**
- **左侧纵向菜单栏**（可滚动）分区排列：**添加卡片**按钮可添加任意卡片：基础值、增伤区、抗性区、防御区、暴击区、增幅反应、擢升、＋加法、激化值、剧变反应、结晶护盾、**属性源 / 基准值源 / ×系数 / ×倍率 / ×(1+基础提升%) / ×精通增益 / 星超导系数**、**计算卡**、**文本**、**变量**、**理想圣遗物**、★结果。
- **计算卡**：一张**无端口、不参与连线**的小工具卡。可**自定义标题**，在其「表达式」里填算式（支持 `+ - * / // % **` 与括号，兼容全角 `× ÷ ＋ － （）`、千分位逗号与换行），卡片底部实时显示计算结果；点 **复制** 可把输出数值复制到剪贴板（纯数字、无千分位/科学计数法，便于直接粘贴到其它输入框）。表达式非法时会显示「错误(原因)」。
- **文本卡片**：一张**无端口、不参与计算**的纯标注卡片，直接输入说明文字即可；与其它卡片一样**可拖动、可拖右下角 `◢` 改变大小**。在卡片上 **右键** 弹出菜单可调字号（字体 ＋/－、常用字号 9/12/16/20/28/40、重置为默认、复制文本）；字号与画布缩放联动，并随 JSON 工程保存/恢复。
- **画布缩放**：左侧菜单栏「画布缩放」区有 **－ / ＋ / 重置 100%** 按钮，也可 **Ctrl+滚轮** 缩放（范围 40%~250%）。缩放会同时调整卡片尺寸、位置、连线与字号；缩放比例随 JSON 工程一起保存/恢复。
- **可拖动改变大小（所有卡片）**：每张卡片**右下角的 `◢` 手柄**都可拖动同时调整宽高（最小 200×110），输入框会随卡片宽度伸展；卡片尺寸会随工程一起保存/恢复。
- **星/月/剧变的「源」已拆分为多个乘区部件**，可自由组合。例如：
  - 月·直伤 = `属性源 → ×系数(3/1.6/1) → ×倍率 → ×(1+基础提升%) → ×精通增益(k=6,den=2000) → 抗性区 → 暴击区 → 擢升 → 结果`
  - 月·反应 = `基准值源 → ×系数(1.8/0.96) → ×(1+基础提升%) → ×精通增益 → 抗性区 → 暴击区 → 擢升 → 结果`
  - 星·超导 = `属性源 → ×系数(hit倍率) → ×倍率 → ×(1+基础提升%) → ×精通增益 → 抗性区 → 暴击区 → 擢升 → 结果`
  - 星·扩散 = `基准值源 → ×系数(0.75 / 2或3) → ×(1+基础提升%) → ×精通增益 → 抗性区 → 暴击区 → 擢升 → 结果`
  - 剧变 = `基准值源 → ×系数(反应倍率) → ×精通增益(k=16,den=2000) → 抗性区 → 结果`
  - 激化值 = `基准值源 → ×系数(1.15/1.25) → ×精通增益(k=5,den=1200) → 结果`（再用加法卡并入基础值）
- 左侧**一键预设**按钮（普通直伤 / 月·直伤 / 月·反应 / 星·超导 / 星·扩散 / 星·扩散直伤 / 剧变反应 / 激化值）会自动用这些拆分部件搭好一条链。**预设不含 ★结果 卡片**（需要汇总时自行拖一张 ★结果 接在链尾）；**预设也不会清空画布**，而是在**空白位置**另起一行创建，可同时保留多条链对比；需要清空时点「清空画布」。
- **变量卡片**：一张**无端口**的卡片，用来**定义全局变量**，每行写 `名称 = 表达式`（可引用前面定义的变量），例如：  ```
  攻击力 = 1000
  倍率 = 200
  基础伤害 = 攻击力 * 倍率
  ```
  定义后，**所有卡片的数值/百分比输入框、计算卡表达式都能引用变量名**，如属性值填 `攻击力+500`、倍率填 `倍率/2`、计算卡写 `基础伤害*2`。未定义的变量会显示「未定义变量: xxx」。变量卡也随 JSON 工程保存/恢复。
- **所有卡片的数字输入框都支持算式**：任意数值/百分比字段都可填 `70+30`、`352+674`、`200*3`、`(100+50)*2`、以及变量名等，程序会先求值再计算（例如倍率填 `70+30` 等效于 `100`）。支持 `+ - * / // % **` 与括号，兼容全角 `× ÷ ＋ － （）` 与千分位逗号；非法输入按默认值处理。
- 每张卡片**左入右出**：从右侧**输出端口**拖到另一张的**左侧输入端口**即可连线；**点击连线**可删除；卡片右上 **✕** 可删除卡片（同时清理相关连线）。
- **连线可读性**：连线为**横平竖直的正交折线**（起点/终点都**垂直于卡片边**水平进出），**直角拐弯处为圆角**，箭头指向目标端口（**不再额外标注 ×/＋/★ 符号**）。**鼠标悬停某张卡片**时，与它相关的连线会以**同色系冷色高亮**（`#0b57d0`）、其余连线**弱化为浅灰蓝**（`#c3ced9`），便于追踪传递关系。
- **理想圣遗物卡片**：调色板「理想圣遗物」可添加一张**带边框的表格**（四列：属性 / 强化区间 / 最高区间 / 平均值，五星满强化）。**可点选单个单元格，或按住拖动选择一块矩形区域**，选中后 **Ctrl+C 复制**（单格复制原文，多格/多行复制为 TSV，可直接粘进 Excel）；未选中时复制整表。表格只读、**没有复制按钮**，卡片可拖动、可拖 `◢` 改大小。
- **＋加法卡片**：默认 2 个输入，点卡片标题栏的 **`＋` 按钮可增加一个输入端口**（最多 12 个），把所有输入逐分量相加（输入个数可变）；入度上限与端口数随工程 JSON 保存/恢复，误点可用 `Ctrl+Z` 撤销。
- 卡片可在画布上**任意拖动、自由排列**（带横/纵向滚动条）。
- 计算方式：从 **★结果** 卡片沿连线**反向溯源**求值；未接入结果的卡片只展示自身输出。每个节点维护 **未暴击 / 暴击 / 期望** 三元组（由暴击区节点产生暴击与期望）；卡片底部在三条路**不同时**会显示 `未暴击 ｜ 暴击 ｜ 期望`，相同则只显示一个输出值。

结果直接显示在画布卡片上：**每张乘区卡片底部会显示本卡的系数与该步输出**（例如抗性区填 `-40` → 卡片显示 `抗性系数 1.200 ｜ 输出 …`；暴击区显示 `暴击系数 / 期望系数`）；★结果卡片与暴击区及之后的卡片显示 **未暴击 / 暴击 / 期望伤害**；若结果链缺少暴击区，结果卡片会标注「← 无暴击区」。

**有效暴击率封顶 100%**：期望伤害中的暴击率按最多 100% 计入，超过 100%（百爆溢出）的部分被截断、不再额外增益。直伤主窗与月/星弹窗的期望值与展示均已封顶（结果显示“有效暴击封顶100%”）。

**输入框支持长算式**：输入框已加宽，方便粘贴/输入如 `352+674+12*3` 这类较长算式。

**保存计算**：主窗口底部与月/星弹窗底部都有 **保存结果…** 按钮。每次保存生成**一个独立文件**（默认文件名含时间戳，如 `直伤伤害_20260909_202705.txt`，可另选位置/名称，互不覆盖）。文件为可读的文本：含保存时间、输入参数快照（分组成 `标签 : 值`）、以及完整的计算过程与结果。

**工程存档（JSON）**：主窗口底部的 **保存工程…** 会把整张画布（节点类型、位置、尺寸、全部参数、连线）存成 `.json`；**打开工程…** 可读取该 JSON 并完整恢复画布（节点 id 自动重映射，计算卡标题/表达式/尺寸一并还原）。**工程名显示在窗口标题**：`原神伤害计算器 · xxx`（优先用存档内的 `name` 字段，旧存档则用文件名，未命名时为「未命名」）。**保存时默认文件名直接用当前工程名**（未命名时用时间戳）。JSON 使用 `ensure_ascii=False` + 缩进，便于阅读与手工编辑。

**撤销 / 重做**：`Ctrl+Z` 撤销、`Ctrl+Shift+Z`（或 `Ctrl+Y`）重做；采用快照式记录，编辑停顿约 0.45 秒自动记一步，最多保留 80 步。

**数字框支持算式**：所有数字输入框都可用 `+ - * / ** ( )` 运算，也兼容 `× ÷ ＋ － ，` 等全角符号，例如属性值填 `352+674`、倍率填 `200*3` 都会先求值再参与计算。非法输入按默认值处理。

**攻/生/防的“大/小增益”前置乘区**：直伤类所输入的属性值按
`最终属性 = 白值×(1 + 大增益%) + 小增益` 计算（例：`1000×(1+46.6%)+311 = 1777`）。
主窗口「① 基础值」与月/星弹窗的直伤类输入均已拆成 **白值 / 大增益% / 小增益** 三格，结果面板会显示最终属性。

### 常用参数（注意单位）

| 分组 | 参数 | 说明 |
|------|------|------|
| 基础值 | 属性值、倍率 | 倍率填百分数（如 `200` 表示 200%）|
| 增伤区 | 增伤区净% | 填增伤+易伤-减伤三者合计的净加成（如 `46.6`）|
| 抗性区 | 敌人抗性 | 填百分数（如 `10` 表示 10% 抗性）|
| 防御区 | 角色/敌人等级、减防、无视防御 | 减防上限 90%、无视防御上限 100% |
| 暴击区 | 暴击率、暴击伤害 | 填百分数 |
| 增幅反应 | 配方、元素精通、反应增伤 | 命中护盾时不计蒸发融化系数 |
| 激化反应 | 超激化/蔓激化、精通、等级 | 附加到常规伤害的激化值 |
| 剧变反应 | 配方、精通、等级、反应增伤 | 独立伤害，不受增伤/减防，不能暴击 |
| 结晶 | 精通、护盾强效 | 计算护盾量 |

## 公式说明（摘自参考页）

**常规伤害**
```
最终伤害 = (基础值 + 激化值 + 基础值加成)
           × (1 + 增伤% + 易伤% - 减伤%)
           × 抗性系数 × 防御系数 × 暴击区 × 蒸发融化系数
```
- 基础值 = 属性值 × 倍率（攻击力/生命值/元素精通/防御力均可）
- 命中护盾（无数值）不计算蒸发融化系数

**抗性系数**
```
抗性 <= 0          : 1 - 抗性/2
0 <= 抗性 <= 75%   : 1 - 抗性
75% <= 抗性        : 1/(4×抗性+1)
```

**防御系数（角色攻击敌人，减防/无视作用在分母敌人防御项）**
```
角色等级+100
----------------------------------------------------------------------------------
(角色等级+100) + (敌人等级+100) × (1 - 减防) × (1 - 无视防御)
```
减防上限 90%、无视防御上限 100%；两者各自相乘作用在敌人防御项上，因此减防会使伤害提升。

**蒸发融化系数**
```
基础系数 × (1 + 2.78×元素精通/(元素精通+1400) + 反应增伤%)
```
基础系数（增幅反应区卡片里以“打”字标注方向并直接显示倍率）：**蒸发·水打火 ×2.0**、**融化·火打冰 ×2.0**、**蒸发·火打水 ×1.5**、**融化·冰打火 ×1.5**。注意系数是**成对相同**的（2.0 一档、1.5 一档），所以选到同一档的蒸发与融化，伤害会相同，这是符合游戏规则的。

**激化值 / 剧变伤害 / 结晶盾量** 等见 `genshin_dmg/damage.py` 内注释。

### 月 / 星反应（进阶，参考 [羽化哲·伤害公式](https://yuhuazhe.cn/zlk/gongshi.html)）

月 / 星反应无视防御、不受益于常规增伤/易伤/减伤，但受益于元素精通与暴击，公式带 **擢升** 与 **基础提升%**：

```
直伤基础 = 直伤系数 × 属性 × 倍率 × (1+基础提升%) × (1 + 6×EM/(EM+2000) + 增伤%)
最终直伤 = (直伤基础 + 额外提升) × 抗性系数 × 暴击区 × 擢升

反应值   = 等级基础(1446.85，95/100级换 1561.46/1674.81)
           × 反应倍率 × (1+基础提升%) × (1 + 6×EM/(EM+2000) + 增伤%)
           × 抗性系数 × 暴击区 × 擢升
```

- **直伤月**：月感电 系数 3 / 月结晶 1.6 / 月绽放 1（属性可为攻击力/精通等）
- **反应月**：月感电 ×1.8、月结晶 ×0.96；月绽放只有直伤
- **星超导**：直伤基础倍率随 hit 数（附着次数 0~12）变化：`1.0, 1.45, 1.5, 1.54, 1.60, 1.64, 1.70, 1.75, 1.79, 1.85, 1.89, 1.95, 2.0`
- **反应星扩散**：风 ×0.75；冰随风涡系数 1~2 → 2、3~6 → 3
- **星扩散直伤**：系数 1
- **多角色分摊**（反应月感电/结晶）：`最高×1 + 第二高×1/2 + 第三高×1/12 + 第四高×1/12`（`distribute_damages`，自动按伤害从大到小排序）。GUI 里可在「角色伤害分摊」填逗号分隔的伤害值来算分摊合计。

### 两处跨参考源的差异提醒

- **激化值**：ellen 页为 `5×EM/(EM+1200)`，羽化哲页为 `5×EM/(EM+2000)`。当前代码沿用 **ellen（+1200）**，如需按羽化哲（+2000）请告知，一处改动即可。
- **扩散倍率**：ellen 页 0.6，羽化哲页 0.65。当前代码沿用 ellen（0.6）。月/星反应则统一按羽化哲（EM+2000）实现。
